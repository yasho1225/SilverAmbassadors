# Design system — Silver Ambassadors

## Idea
On this page, **Sunday connection** becomes a **full-bleed moment of gathering**, with the club name as the first thing you read.

## Direction
Silver / charcoal · light canvas · brand-forward hero · quiet motion.

## Colour
| Token | Value | Use |
| --- | --- | --- |
| `--bg` | `#eef0f3` | Cool silver mist page |
| `--surface` | `#ffffff` | Panels |
| `--surface-2` | `#e2e5ea` | Soft fill |
| `--ink` | `#16181d` | Text |
| `--muted` | `#5f6773` | Secondary |
| `--accent` | `#1e2430` | Primary actions |
| `--accent-ink` | `#f4f5f7` | Text on accent |
| `--silver` | `#8b939e` | Quiet metal accent |

Not used: soot+lime dark mode, purple SaaS, cream–terracotta.

## Type
- **Display:** Syne 700–800, tracking tight
- **UI / body:** DM Sans 400–600

## Imagery
- Atmosphere (Unsplash): hero, mission, activities
- Club photos: `/gallery` only via `galleryPhotos`

## Motion
Lenis + GSAP: hero fade/rise, section reveals, soft image scale on scroll.
